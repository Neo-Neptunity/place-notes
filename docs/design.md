# ここ付箋 設計

付箋を、ファイルやフォルダに貼る MOD。0.1.0。

## ねらい

- 紙の付箋は、場所に貼れるが、はがれる・失くす。デジタルのメモは、残るが、「どこで」の手がかりから離れる。**場所に貼れて、残る**付箋にする
- 使い方は「選んで、書いて、Enter」だけにする。設定も、ファイルの準備も要らない
- 付箋ワールド（`sticky-world`）は、みんなで貼り合う場。こちらは、自分のファイルとフォルダに貼る、個人向け。同じ共有フォルダを同期している自分の PC どうしでは、そのまま届く

## 使い方

| したいこと | 操作 |
|---|---|
| ファイルに貼る | 行を選んで、下の欄に書いて Enter。行にマウスを乗せると出る「＋ 付箋」でも選べる |
| フォルダ全体に貼る | 何も選ばずに書いて Enter。右の「このフォルダの付箋」に出る |
| 子フォルダに貼る | そのフォルダの行を選んで書く。付箋はそのフォルダの中に入る |
| 書き直す | 付箋を押す。打つたびに自動で残る。Esc か外を押すと閉じる |
| 色を変える | 書き直しの中の色の丸。次に貼る色は、下の欄の右の丸 |
| 貼りなおす | 付箋をつかんで、別のファイルの行・横に並んだフォルダの行・右の掲示板へ落とす。落とせる行が光る。「元に戻す」が8秒出る |
| ずらす | 付箋をつかんで、同じ行の中で放す。行の外へは出ない |
| 大きさを変える | 付箋の右下の角をつかむ。角を2回押すと、もとに戻る |
| 位置と大きさをもとに戻す | 付箋を右クリック |
| はがす | 付箋の「はがす」。消えない。下に「元に戻す」が8秒出る |
| 探す・戻す・消す | 上の「すべての付箋」。ことばで探す・はがした付箋を貼りなおす・完全に消す |
| ほかのビューから貼る | 右クリックの「ここ付箋 › 付箋を貼る」。入力欄が1つ出て、貼って終わる |
| ほかのビューから見る | 右クリックの「ここ付箋 › 付箋つきで開く」 |

打ち始めると、書く欄に入る。↑↓ で行を選び、Enter で開き、F2 で名前を変え、Delete でごみ箱へ（本体が確かめる）。

## 付箋の置き場所

付箋は**貼った場所のフォルダの中**に保存する（本体の `folderData`。そのフォルダの `.explorer_plus\view.neo.place-notes.json`）。

| 付箋の種類 | 保存先 |
|---|---|
| ファイルに貼った付箋 | そのファイルがあるフォルダ |
| フォルダ全体に貼った付箋 | そのフォルダ自身 |
| 子フォルダに貼った付箋 | その子フォルダ自身 |

- フォルダを動かす・名前を変える・コピーする・同期する・人に渡すと、付箋もいっしょに付いていく。**付箋は場所から離れない**
- 子フォルダの付箋は、親から見ても行に出る。子フォルダの行には、中の付箋の数（📝 3）も出るので、開く前に、付箋のある場所が分かる
- 付箋が0枚になったら、データのファイルも消す。使っていないフォルダに跡を残さない
- 書けないフォルダ（`C:\` の直下など）では、本体がこのビューの保存場所に置く

```json
{ "v": 1, "notes": [
  { "id": "nmvq5nqrfwmq1", "text": "金曜までに数字を直す", "color": "yellow",
    "t": 1793073488955, "u": 1793073488955, "gone": 0,
    "on": { "name": "企画書_v3.docx", "ids": ["70334", "1204"] } } ] }
```

- `t`：貼った時刻、`u`：直した時刻、`gone`：はがした時刻（0 なら貼ってある）
- `on`：貼ったファイル。無ければフォルダ全体。`ids` は、見てきたファイルID（PC ごとに違うので、増えていく。新しい6つまで）
- `w`・`h`・`x`・`y`・`z`：大きさ・ずれ・重なる順（下の「位置と大きさ」）。ふつうの付箋には、このキーは無い
- 付箋は 800 字まで、1フォルダ 300 枚まで。いちばん大きい形でも本体の 1MB に収まる

## 位置と大きさ

貼ったあとで、付箋を少しずらしたり、大きさを変えたりできる。見た目の決まりは今までどおりで、付箋そのものをつかむだけ。

- **大きさ**：`w`（幅 140〜560px。ふつうは 320）と `h`（高さ 64〜480px。ふつうは文に合わせる）。付箋の右下の角（折れ目）をつかんで変える。縦に4px以上動かさなければ、高さは文に合わせたまま。高さを決めた付箋は、入りきらない文を隠す。書き直すときは、付箋いっぱいに広がる。角を2回押すか、右クリックの「大きさと位置をもとに戻す」で、ふつうに戻る
- **ずれ**：`x`・`y`（-600〜600px）。付箋がふつうに並ぶ位置からの動き。**同じ行の中で放す**と、そこまでずれる。行（掲示板なら付箋の並び）の外へは出ない。画面の幅が変わっても、ふつうの位置からのずれなので、付箋が行から外れることはない
- つかんでいる間は、付箋の写しが指に付いてくる。行の外へ出ても欠けず、落とせる行（ファイルの行・フォルダの行・掲示板）が光る。一覧の上下の端に近づくと、一覧が動く
- **別の行に落とすと、貼りなおす**：ファイルの行ならそのファイルに、フォルダの行ならそのフォルダの中に、掲示板ならこのフォルダ全体に貼る。子フォルダの付箋を、ほかの行や掲示板へ出すこともできる。別のフォルダへの貼りなおしは「先に新しいほうへ書く → 元から外す」の順で、途中で止まっても付箋は失われない。付箋のID が同じなので、やりなおしても増えない。「元に戻す」で、もとの貼り先へ帰る
- **最後につかんだ付箋は、重なったとき手前に出る**：つかんで放す・大きさを変える・貼りなおすたびに、`z`（重なる順。大きいほど手前）を、そのフォルダの付箋でいちばん大きい値の次にする。もう手前なら書き直さない。書き直している付箋は、いつも手前
- 貼り先が変わると、並ぶ位置も変わるので、ずれは外す。大きさと、貼った・直した時刻は残す
- 大きさやずれを変えても、`u` は変えない。付箋の下の「3日前」が「たった今」にならない
- 付箋に保存する。同期でほかの PC にも届く。書き込むのは、放したときの1回だけ

## 貼り先の見つけ方

ファイルの付箋は、フォルダを開くたびに、今のファイルと突き合わせる。

1. ファイルIDで探す（`ids` の新しいほうから）。名前を変えても付いていく
2. なければ名前で探す。別の PC ではファイルIDが違うので、名前で見つかる
3. 見つかったら、新しい名前と、この PC のファイルIDを付箋に書き戻す（`learn`）。次からは、この PC で名前を変えても付いていく。書き戻しは、変わったときだけ。同期で行き来しても、繰り返さない
4. どちらでも見つからなければ、**はがれた付箋**

## はがれた付箋

ファイルを別のフォルダへ動かすと、付箋は元のフォルダに残る。右の掲示板に、点線の付箋で出る。

- ファイルIDから今の場所を探す（`ep.resolve`）。見つかって、名前が同じなら、「いまは○○にあります」と **連れていく** を出す。名前が同じものだけ信じるのは、別の PC のファイルIDが、たまたま別のファイルと重なっても間違えないため
- 連れていく：新しい場所のフォルダへ移り、着いたら付箋を移す。先に新しい場所に書いて、そのあと元から外す。途中で止まっても、付箋は失われず、多くても2枚になるだけ。付箋のID が同じなので、もう一度やっても増えない
- **このフォルダに貼る**：フォルダ全体の付箋にする
- ごみ箱へ送ったファイルの付箋も、同じように残る

## はがしても消えない

- はがすと `gone` に時刻が入るだけで、付箋は残る。「すべての付箋」の「はがした」から、貼りなおせる。完全に消すのは、そこから、確かめを通したときだけ
- 書き直しで文を空にしても、付箋は消えない。元の文のまま

## すべての付箋

開いた場所の付箋の写しを、この PC の `ep.storage`（`place:<場所>`）に覚えておく。

- 場所ごとに1つの値。付箋の文・色・時刻・貼り先のファイル名だけを持つ
- 開くたびに、`ep.resolve` で場所を引き直す。動かした場所は新しいパスに直り、消えた場所は「場所が見つかりません」と出る。**フォルダが消えても、付箋は索引に残る**。要らなければ「記録から消す」
- この PC で開いていない場所の付箋は、まだ載らない。別の PC で貼った付箋は、その場所を開くと載る
- 場所をまとめて探して、新しい付箋のある場所から順に並べる

## 同期とぶつかり

- 書くときは、必ず読み直してから、その上に重ねて書く（`update`）。ほかのウィンドウや同期で先に変わっていても、巻き戻さない。同じフォルダへの書き込みは、1つずつ順に行う
- 画面は、フォルダが読み込まれたとき・ウィンドウに戻ったとき・15秒おきに、付箋を読み直す。同期で届いた付箋が出る
- 書きかけの付箋と、押している最中のボタンは、画面の作り直しで消さない。作り直しは、書き終えたあと・手を離したあとにまとめて行う
- **ぶつかるのは、2台の PC が、同じフォルダの付箋を、同期が届く前に書いたとき。** OneDrive が競合したコピーを作ることがある。ひとりで使うぶんには、まず起きない。何人かで同じ場所に書くなら、付箋ワールドを使う

## 大きなフォルダ

- 1500件のフォルダを試した。開くのも、貼るのも、作り直しも、数十ミリ秒
- 行は、見えているものだけ描く（`content-visibility`）。見えていない行の高さは、作り直すと見積もりに戻るので、いちばん上に見えている行を覚えて、作り直したあとに、同じ位置へ戻す。見積もりの高さは、行の中身の高さに合わせる（枠の分は別に足される）
- 子フォルダの付箋は、300個まで、4つずつ並べて先読みする

## 本体に頼んでいること・使っていること

- `uses`：`entries`・`icons`・`modified`・`links`・`folderData`。通信・ファイルの中身・ファイルを作る許可は使わない
- 付箋は、フォルダの中の `.explorer_plus` にだけ書く。ほかのファイルは書き換えない。名前の変更・ごみ箱・ドラッグは、使った人が頼んだときだけ、本体に頼む
- 本体に頼みたいこと：フォルダの付箋があるかを、一覧の段階で知らせるしくみ（今は、子フォルダを1つずつ読んでいる）。ほかのビューの行に、付箋の印を出すしくみ

## ファイル

```
mod/
  manifest.json   名札・使う情報・右クリックの項目・設定
  index.js        つなぎ役：状態・フォルダの読み込み・貼る・書き直す・はがす・連れていく・キー操作・右クリックから貼る
  store.js        付箋の決まり：形・確かめ・変える・貼り先を探す・索引・探す・パスと日付（画面も通信も持たない）
  data.js         保存：読み直してから書く・同じフォルダは順に・索引
  view.js         画面の HTML（文字は必ず esc を通す）
  style.css       見た目
dev/              試験の道具（README を見る）
docs/             この文書と、画面写真
```
