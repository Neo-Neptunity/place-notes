# ここ付箋 開発用のテスト

MOD 本体は `place-notes/mod/`。配る zip に入れたくないので、テストは本体に置かず、ここにまとめる。
`unit.mjs` は `node` だけで動く。`browser.mjs` は、Edge（なければ Chrome）が入っていれば動く。どちらも EP_MODs から流す。

| ファイル | 内容 | 使い方 |
|---|---|---|
| `unit.mjs` | 画面を持たない部品の試験：付箋の形と確かめ・変える（元を変えない・変わらなければ同じ doc）・**大きさとずれ（範囲に収める・0でふつうに戻す・更新の時刻を変えない・貼りなおすとずれだけ外れる）**・上限・**貼り先の見つけ方（IDで追う・名前で探す・別の PC のIDを覚える・書き戻しが繰り返さない・はがれた付箋）**・探す・パスと日付・**保存（同時の書き込みが両方残る・同期で届いた付箋を巻き戻さない・壊れたデータ・0枚でファイルを消す・大きすぎれば断る・IDが合わない・フォルダを動かしても付いていく・索引）**・**右クリックから貼る（見えない所）**・manifest と書き方の決まり（通信しない・（）の補足を画面に入れない・文字は esc を通す） | `node place-notes/dev/unit.mjs` |
| `browser.mjs` | 本物の `index.js` を、ヘッドレスの Edge で動かす。操作して確かめ、画面を PNG に撮る | `node place-notes/dev/browser.mjs [出力フォルダ] [--scenario=…] [--w=1100 --h=760] [--dpr=1]` |
| `fake-host.mjs` | 偽の explorer_plus。メモリの中のフォルダ。本物と同じく ID が合わなければ断り、フォルダのデータはフォルダにくっつく（動かせば付いていく）。名前の変更・動かす・消すと、フォルダを読み直す | |
| `seed.mjs` | 試験用の種：「新商品の企画」に、ファイル・フォルダ・動かされたファイルの付箋とはがした付箋。「家の手続き」にもう1か所 | |

## browser.mjs のシナリオ
- `look`：「この場所」・選んだ行・書き直し・すべての付箋・はがした付箋・暗い画面・狭い画面・別のフォルダ・空の掲示板。見た目を調整するときに使う
- `layout`：付箋をずらす・大きさを変える・つかんでいる最中（写しと光る落とし先）。見た目を調整するときに使う
- `flow`：貼る（ファイル・フォルダ全体・子フォルダ）・Shift + Enter・書き直しの自動保存・**書き直しの最中に同期が届いても書きかけが残る**・色・はがす・元に戻す・**連れていく**・名前を変える・別のフォルダへ動かす・このフォルダに貼りなおす・右クリック・キー操作・名前の変更・しぼりこみ・すべての付箋（探す・貼りなおす・はがす・消す・行く・場所が消えた）
  - **本物のマウス操作で付箋をつかむ**：ファイルの行・フォルダの行・掲示板へ落とす（つかんでいる間の写しと光る行・元に戻す・子フォルダの付箋を掲示板へ・掲示板の付箋をフォルダへ）・同じ行の中でずらす（更新の時刻は変わらない・作り直しても残る・行の外へは出ない）・角で大きさを変える・角を2回押してもとに戻す・右クリックでもとに戻す・別のフォルダへ貼りなおすと大きさは付いていきずれは外れる・つかんで放しても書き直しが開かない
- `big`：1500 件のフォルダ。貼る・奥までスクロールして作り直しても見ている所が動かない

## ヘッドレスで気をつけること
- JS の `scrollIntoView` の直後の最初のマウス操作で、動かした分が元に戻ることがある。`browser.mjs` の `settle` は、マウスを乗せて待ち、同じ位置が2回続くまで測りなおす
- 押した直後に打ち始めると、`setTimeout` の focus が間に合わず取りこぼす。本体の画面では、押した処理の中で、すぐに書く欄へ入る

## 確かめられないこと
- 本物の explorer_plus の中での動き。偽の本体で代用している。とくに、右クリックの「付箋を貼る」（見えない所で動かして入力の画面を出す）・名前の変更のあとのフォルダの読み直し・`ep.resolve` が動かしたファイルを見つけるか・キーが MOD の画面へ届くか・本体のドラッグ
- OneDrive の同期そのもの。別の PC は、データを直接書き換えて、まねている
- 2台の PC が同時に同じフォルダへ書いたときの、OneDrive の競合コピー
